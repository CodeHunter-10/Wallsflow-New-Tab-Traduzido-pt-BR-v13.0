# Como instalar o Wallsflow em português pelo GitHub (passo a passo)

**Você nunca usou o GitHub? Nunca instalou uma extensão manualmente? Não tem problema.**

Este tutorial vai ensinar você a baixar e instalar o Wallsflow em português no seu navegador, mesmo que seja a primeira vez que você acessa o GitHub.

Não precisa saber programação, não precisa escrever código e não precisa instalar nenhum programa adicional.

## Antes de começar: sobre esta versão do Wallsflow

Ela utiliza como base o **Wallsflow versão 13** e tem como objetivo facilitar o acesso ao projeto para quem prefere utilizar o navegador em português.

- Não foram criadas ferramentas ou recursos adicionais.
- A modificação consiste na tradução do projeto original para o português.

**Créditos e autoria:** todo o crédito pelo projeto original, sua concepção e desenvolvimento pertence ao criador do **Wallsflow New Tab**. Esta versão em português é apenas uma modificação não oficial baseada no trabalho original, e não pretende reivindicar sua autoria.

## 1. Você já está na página do projeto no GitHub

O GitHub é um site onde desenvolvedores armazenam e compartilham projetos.

Você não precisa criar uma conta para baixar um projeto público.

Na página inicial do projeto Wallsflow, procure um botão verde chamado **Code**.

1. Clique no botão verde **Code**.
2. Vai aparecer um pequeno menu.
3. Procure a opção **Download ZIP**.
4. Clique nela.

Pronto! O download do projeto começará automaticamente.

## 2. Encontre o arquivo que acabou de baixar

Agora precisamos localizar o arquivo no seu computador.

1. Abra a pasta Downloads do Windows.
2. Procure o arquivo ZIP do Wallsflow que acabou de baixar.
3. Clique com o botão direito sobre ele.
4. Escolha **Extrair Tudo...**.
5. Na janela que aparecer, clique em **Extrair**.

O Windows vai criar uma pasta com os arquivos do Wallsflow.

**Importante:** não tente instalar a extensão diretamente pelo arquivo ZIP. Primeiro precisamos extrair seu conteúdo.

## 3. Abra a página de extensões do Chrome

Agora vamos preparar o navegador para receber a extensão.

1. Abra o Google Chrome.
2. Na barra de endereço, onde você normalmente digita os sites, escreva:

   `chrome://extensions`

3. Pressione Enter.

Você será direcionado para a página de gerenciamento de extensões.

## 4. Ative o modo desenvolvedor

Na página de extensões, procure o botão chamado **Modo do desenvolvedor**.

Normalmente ele fica no canto superior direito da tela.

1. Localize essa opção.
2. Clique para ativá-la.
3. Você verá novos botões aparecerem na página.

Não se assuste: isso é necessário para instalar extensões que foram baixadas diretamente do GitHub.

## 5. Carregue o Wallsflow no navegador

Agora vem a parte mais importante.

1. Clique no botão **Carregar sem compactação**.
2. Uma janela do Windows será aberta.
3. Navegue até a pasta onde você extraiu o Wallsflow.
4. Selecione a pasta principal da extensão.

**Como saber se você selecionou a pasta correta?**

Procure um arquivo chamado:

`manifest.json`

A pasta selecionada precisa conter esse arquivo diretamente, e não apenas uma subpasta onde ele está guardado.

5. Selecione a pasta correta.
6. Clique em **Selecionar pasta**.

O Chrome vai carregar a extensão automaticamente.

## 6. Pronto! O Wallsflow está instalado.

Se tudo ocorreu corretamente, o Wallsflow aparecerá na lista de extensões instaladas.

Você poderá:

- Ativar ou desativar a extensão.
- Consultar os detalhes.
- Gerenciar suas permissões.
- Remover a extensão quando quiser.

O Wallsflow também substitui a página de nova aba do navegador.

Para conferir, abra uma nova aba pressionando:

`Ctrl + T`

A página do Wallsflow em português deverá aparecer.

## 7. Como deixar o Wallsflow sempre acessível

Você pode fixar a extensão na barra superior do Chrome.

1. Clique no ícone de quebra-cabeça (**Extensões**), próximo à barra de endereço.
2. Procure o Wallsflow na lista.
3. Clique no ícone de alfinete ao lado dele.

Agora o ícone do Wallsflow ficará visível na barra do navegador.

## 8. Está usando Microsoft Edge?

O procedimento é praticamente igual.

Em vez de acessar `chrome://extensions`, digite:

`edge://extensions`

Depois:

1. Ative o **Modo do desenvolvedor**.
2. Clique em **Carregar sem compactação**.
3. Selecione a pasta extraída que contém o `manifest.json`.

## 9. Problemas comuns

**O botão Carregar sem compactação não aparece.**

Verifique se o modo desenvolvedor está ativado.

**O Chrome apresenta erro ao carregar a extensão.**

Confira se você selecionou a pasta correta e se o arquivo `manifest.json` está dentro dela.

**Aparece uma mensagem dizendo que o manifesto está ausente.**

Provavelmente você selecionou a pasta errada. Entre nas subpastas até encontrar aquela que contém diretamente o arquivo `manifest.json`.

**A extensão foi instalada, mas não aparece na nova aba.**

Verifique se ela está ativada em `chrome://extensions` e abra uma nova aba com `Ctrl + T`.

**O projeto recebeu uma atualização no GitHub.**

Para instalar uma versão atualizada, baixe o novo ZIP, extraia os arquivos e carregue a nova pasta pelo gerenciamento de extensões. Caso substitua os arquivos na pasta que já está instalada, clique no botão de atualizar da extensão em `chrome://extensions`.

Lembre-se de manter a pasta da extensão salva no computador. Não a exclua depois da instalação, pois o navegador utiliza os arquivos dessa pasta para executar a extensão.

## 10. Uma observação importante sobre segurança

O GitHub é uma plataforma de hospedagem de projetos, não uma garantia de que todo projeto seja seguro.

Instale extensões somente quando confiar na origem do projeto e compreender as permissões solicitadas.

Esta modificação utiliza a estrutura e as permissões do projeto-base. Antes de instalar, consulte as permissões apresentadas pelo navegador.
